# LinkedIn Skills — Jessie van Breugel

Skills in this folder are from Jessie van Breugel's LinkedIn system, designed for coaches, consultants, and B2B service providers selling high-ticket services. They cover the full LinkedIn content and conversion funnel.

> These are on trial. Graduate individual skills to the main `skills/` folder once proven useful.

---

## Skills

| Skill | Use when |
|---|---|
| **linkedin-post-generator** | Writing a LinkedIn post from scratch, a rough idea, or a client story |
| **viral-hook-writer** | The opening line of a post needs to stop the scroll and earn the "see more" click |
| **comment-strategy-writer** | Writing comments on others' posts to drive profile visits and get noticed |
| **cta-handraiser-writer** | Crafting a post CTA that converts readers into inbound leads without being pushy |
| **dm-conversation-skill** | Turning post engagement into booked calls via DM, without cold pitching |
| **content-calendar-planner** | Building a weekly posting plan, content pillars, or a system to stay consistent |
| **linkedin-profile-optimizer** | Auditing or rewriting a LinkedIn profile to convert visitors into conversations |

---

## How these differ from the Turing Works LinkedIn skills

The TW skills (`james-linked-post`, `polish-linkedin-post`) are tuned for **Alasdair and James's voices** — founder-led content, Australian English, Turing Works brand context.

These Jessie skills are **generic B2B coach/consultant templates** — useful as a base or for client work, but will need voice adaptation for personal use.
